# billtree

Per-resource AWS bill breakdown from your own Cost and Usage Report. One Python file, standard library only, runs locally.

An open rebuild inspired by [@brankopetric00's AWS billing tree](https://x.com/brankopetric00), which was itself inspired by @tobi's datatree. Built with Claude Opus 5.5.

```
python3 billtree.py ./cur-export/ --top 15 --json bill.json --html bill.html
```

- Reads legacy CUR and CUR 2.0 CSV exports, `.csv` or `.csv.gz`, single files or whole folders
- Builds the tree account > service > region > resource in one streaming pass
- Prints the most expensive resources, writes a compact JSON your AI agent can read in one prompt, and a self-contained HTML treemap
- No AWS credentials, no Cost Explorer API calls, nothing leaves your machine

## Benchmark

One synthetic CUR 2.0 month, 1,000,000 hourly line items (104 MB CSV, 17 MB gzipped), generated by `bench/make_cur.py` with a fixed seed. One run, one core of an AMD EPYC 9645, Python 3.

| | |
|---|---|
| Line items read | 1,000,000 |
| Wall time | 1.72 s |
| Peak memory | 17.8 MB |
| Resources found | 1,833 |
| Total vs generator | $147,419.78 vs $147,419.78 |
| JSON for the agent | 55 KB |

Reproduce:

```
python3 bench/make_cur.py /tmp/cur.csv.gz 1000000   # prints the exact total
python3 billtree.py /tmp/cur.csv.gz --json /tmp/bill.json --html /tmp/bill.html
```

## Getting the CUR

Billing console > Data Exports > create a CUR 2.0 export to S3 with resource IDs included, then `aws s3 sync s3://<bucket>/<prefix> ./cur-export/`.
